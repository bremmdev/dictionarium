## Left for a decision

These are in the PR description, not the code:

- **The stem-class validation messages have Latin in flat strings.** "… — pater, patrum; urbs, urbium." (`utils/entries/rules.ts`). `FieldError` takes a `string`, as every other field message does, so marking it means giving messages structure, like `FormLine.enclitic` in the last run. The older terminations messages have the same limit.
- **The _projected v1_ figure shows a bare "—"** when there is no pace. Screen readers read it as "dash" or skip it. The sentence below says why, so this may be fine. The deleted `Endings.tsx` used `aria-hidden` on the dash plus hidden text ("no fixed ending"), and that would work here too.
