## Needs a decision

1. **The tense timeline's `alt` names six Latin forms** (`Translating.tsx:127`): _salūtāveram_, _salūtābam_, _salūtāvī_, _salūtō_, _salūtābō_, _salūtāverō_. `alt` is a flat string, so they're read with the English voice. This week the alt only gained _salūtāverō_; the pattern is older. The vault's rule says a mixed label has to become content. For an image that means one of:
   - `alt=""` plus a visually hidden description with `<span lang="la">` runs, which loses the link between the image and its text;
   - a `<figure>` with a visible `<figcaption>` that carries the forms, which changes the page;
   - keeping it as it is, on the same grounds as announcements: the visible SVG is the real content and the alt is a safety net.
2. **Health problem messages quote Latin data values** (`admin_.health.tsx:100`, `:191`, `:212`, from `utils/health/checks.ts`). Examples: `lemma_plain is "amo", should be "amo"` and `principal_parts is "amō, amāre, …" — …`. They're plain strings shared with `npm run check`, so they can't carry `lang`. Marking them would mean returning structured messages (text plus Latin parts) from the checks, for an admin-only page. Keeping them as they are seems reasonable: they are diagnostics about field values, not prose.
